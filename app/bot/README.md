# Следующий этап

Telegram-бот отложен до приемки основного MVP согласно разделу 17 ТЗ. Отправка сообщений, хранение подписок и работа с Telegram API сейчас не реализованы. Токены не запрашиваются. Будущая реализация должна добавить явную подписку, темы/регионы/периодичность, лимиты, отписку и отправку только подтвержденных сигналов.
