# Локальная обработка и ограничения

Приемка: точные Hugging Face commit SHA записаны в contracts/models.lock.json. Установка отдельно: pip install -e '.[nlp]', затем при доступном интернете python -m scripts.install_models --model e5. Для sentiment необходима проверка лицензии и явный --license-reviewed. Рабочие процессы не скачивают веса. Загрузка проверяет PROVENANCE.json и совпадение версии с lock; это защита от случайной подмены версии, не криптографическая аттестация каталога. Веса E5 и sentiment в рамках текущей приемки не установлены, inference этих моделей остается непроверенным. Natasha 1.6.0 включает NER-веса в Python-пакете, ее фактический inference проверяется обязательным тестом test_ner_actual_inference.

Без моделей доступен явно обозначенный baseline `keywords-1.0.0`: многометочная классификация по подстрокам. Числа baseline — эвристические оценки, не калиброванные вероятности. Это не обученный тематический классификатор. Метод языка `cyrillic-ratio` также эвристический. География `dictionary-1.0.0` сохраняет совпадения и роль mention, не присваивает место события по адресу СМИ. Словарь форм ограничен; неоднозначные города и точное извлечение места события требуют расширения и разметки.

Для семантического поиска поддержан [intfloat/multilingual-e5-small](https://huggingface.co/intfloat/multilingual-e5-small): 384 измерения, MIT, multilingual retrieval, около 118M параметров. Выбор обоснован задачей поиска и умеренным размером, а не названием модели. На CPU предусмотрен запуск; ориентир для всего приложения с ML 4–8 GB RAM, реальное потребление нужно измерить. Модель не валидирована на корпусе детской социальной повестки.

Опциональная тональность: [cointegrated/rubert-tiny-sentiment-balanced](https://huggingface.co/cointegrated/rubert-tiny-sentiment-balanced). Небольшой RuBERT для коротких русских текстов, три класса. Карточка автора показывает заметную зависимость качества от домена; в частности news macro F1 0.66. Поэтому не использовать оценку как факт. В карточке не указана явно лицензия весов: перед установкой необходимо подтвердить условия правообладателя. По умолчанию модель не устанавливается. Применяется sigmoid согласно авторскому примеру; confidence означает выход модели, не проверенную вероятность. Длинные тексты обрезаются до 512 токенов. Это ограничение показывается здесь и должно учитываться аналитиком.

Загрузка моделей не происходит при запуске сервисов. Сначала отдельно загрузите проверенный snapshot модели с конкретным commit SHA и safetensors, сохраните файлы в models/e5 и, после проверки лицензии, models/sentiment. Укажите SHA в MODEL_VERSION / SENTIMENT_VERSION. Установите NLP_ENABLED=true только для e5. Контейнеры загружают local_files_only и не выполняют remote code; внешние AI API отсутствуют. Начальная установка библиотек и весов требует интернета; дальнейший inference автономен.

Для переобработки: POST /api/v1/media/reprocess с Bearer ADMIN_TOKEN. Подтвержденные и отвергнутые ручные метки сохраняются. Исходный текст отделен от результатов; ошибки хранятся в media.processing_errors. При сбое всего ML-транзакция откатывается, публикация остается failed и доступна для повторной обработки. Текущая версия выполняет этапы одной транзакцией на публикацию; отдельных очередей этапов нет.

Перед промышленным использованием нужен размеченный отложенный корпус: precision/recall/F1 по каждой теме, точность event-vs-mention по географии, macro-F1 и калибровка тональности, retrieval recall@k. Набор unit-тестов не заменяет такую оценку.
