# Технический аудит · 24 ноября 2026

Область: только child-media-monitor, существующие соседние проекты и удаленные репозитории не изменяются. Исходный код сохранен, исправления дополняют работающие компоненты.

| Компонент | Выявлено | Исправление / проверка |
|---|---|---|
| PostgreSQL / pgvector | Только пропускаемый одиночный тест, нет реального прогона | Обязательный PostgreSQL 16 service в CI; extension/index/schema/API/vector тесты |
| Alembic | Начальный SQL снимок; нет privacy-схемы и согласованных регионов | Дополнительные 0002 и 0003, существующий 0001 не переписан |
| RSS | GUID/UUIDv5, robots, размер и timeout работают; сетевые ошибки могли содержать URL | Синтетические локальные RSS, тест повторной загрузки и обновления; только классы ошибок в логах |
| Дедупликация | Стабильный ключ источник+GUID; перепечатки раздельны | Проверка 2x загрузки и обновления без изменения post_id |
| Публикация | Критично: исходные тексты были открыты в API | Отдельная privacy_checks; fail closed, safe excerpt, защита detail/search/digest/summary/trends |
| NLP | Эвристическая тематика/география; E5 и sentiment не проверены | Реальный Natasha NER, синтетический корпус/метрики; опциональные модели остаются неполной проверкой |
| Ручные решения | Коррекции сохраняются; privacy-проверки не было | Закрытая очередь безопасных представлений и ручное решение, аудит без исходных ПД |
| core | ISO media и цифровые региональные идентификаторы несовместимы | Пакет shared-contracts из существующего regional-контракта, явное отображение 83 кодов, миграция без удаления справочников |
| API | Есть фильтры и OpenAPI; полная выдача исходных данных небезопасна | Из публичной схемы удалены external_id/text_hash; не выдаются raw_metadata/author; URL очищается |
| Streamlit | Восемь страниц, карта пока таблица | AppTest всех разделов + Playwright против Compose с безопасными скриншотами |
| Docker | Не проверялся без локального Docker | Изолированный CI job, health API/UI/worker, restart БД, проверка persistence |
| Публикация кода | Не было CI | PR workflow, зависимости/линтер/синтаксис/секреты/уязвимости/лицензии |

Оставшиеся риски: DNS rebinding требует egress-фильтра при недоверенном реестре; robots не заменяет условия издателя. Natasha + regex не обнаруживают все ПД; чувствительный детский контекст и сбой NER блокируют автоматическую выдачу. Нельзя заявлять гарантированную анонимность. Общий контракт — технический кандидат, не согласованный стандарт. Итоговые фактические результаты — mvp-readiness.md, не сам факт наличия workflow.
