Новый публичный репозиторий: https://github.com/ilyachurekov-msu/child-media-monitor . Существующие репозитории не изменялись. PR: https://github.com/ilyachurekov-msu/child-media-monitor/pull/1 (черновик, без merge). Доступ GitHub App предоставлен, код находится в codex/mvp-acceptance; main содержит только исходный README.

Метрики scripts.evaluate: 12 синтетических примеров. Темы: TP=8, FP=0, FN=0, micro precision/recall/F1=1.0. PII на уровне документа: TP=6, FP=0, FN=0, precision/recall/F1=1.0. Геоупоминания: TP=1, FP=0, FN=0; precision/recall/F1=1.0. Это маленький development-набор, на котором разрабатывались правила, **не независимая оценка качества** и не основание заявлять 100% надежность. E5 и sentiment inference не выполнены. Их конкретные commit SHA получены с Hugging Face и закреплены в contracts/models.lock.json.

Синтаксис (compileall), pip check и линтер Ruff прошли в CI. Первоначальный диапазон PyArrow18–19 был совместим с NumPy1, но Linux pip-audit обнаружил уязвимость. Итоговое исправление — PyArrow23.0.1+ (<24) и setuptools84.1+, проверенные повторными тестами и сканированием; проверки не отключались и исключения уязвимостей не добавлялись.

При изменении уже доступной публикации на чувствительную raw-текст сохраняется отдельно, публичная выдача немедленно блокируется и прежний embedding удаляется. Эта ситуация проверяется отдельным интеграционным тестом. Браузерные тесты используют только синтетические данные; артефакты хранятся 7 дней. Реальные RSS не являются обязательной частью CI.

Доказательство: [успешный CI run 45277750853](https://github.com/ilyachurekov-msu/child-media-monitor/actions/runs/45277750853), код 29f20095aa460b8a44222f4920c8dc38c62f8424. Jobs test и containers завершились success. Артефакты test-reports и synthetic-ui-screenshots доступны в этом запуске; срок 7 дней, затем CI воспроизводит их заново. Изменения финального отчета запускают еще один обязательный PR CI.

Непроверенные или неготовые части: фактический inference E5 и sentiment; независимый репрезентативный корпус и оценка privacy recall на нем; согласование shared-contracts с владельцами остальных модулей и миграция legacy source UUID соседнего проекта. Семантический поиск без установленной модели отвечает 503, а не выдает фиктивные результаты. Интерактивная карта оставлена следующему этапу согласно заданию; используется проверенная таблица регионов. Telegram-бот и новые коннекторы не входили в этот этап.

Итог: базовый MVP v0.1.0 прошел перечисленные технические проверки и подготовлен для локальной аналитической апробации. Это не подтверждение промышленной надежности автоматического удаления ПД или полного согласования платформенной интеграции. Ограничения моделей документированы согласно разрешенному в задании варианту. Docker Desktop владельцу не требуется. PR оставлен черновиком для проверки владельцем; ни merge, ни release, ни production deployment не выполнялись.
